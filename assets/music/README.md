# Background music folder

Upload all your MP3 music files directly into this folder: `assets/music/`.

The editor uses the AI-detected scene mood (comedy, romantic, emotional, suspense, action, or interesting) to select a suitable track. To help it match tracks more accurately, include mood words in filenames when possible, for example:
- `romantic_soft_song.mp3`
- `sad_emotional_piano.mp3`
- `suspense_tension.mp3`
- `action_epic.mp3`
- `funny_comedy.mp3`

If no filename matches the detected mood, the editor chooses the first available audio file.

Supported formats: MP3, WAV, M4A and AAC.
